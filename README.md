# Grog — Free Offline Canvas Notes App

**Write, sketch, and mind map — completely offline. No account. No ads. Free forever.**

Grog is a free offline canvas notes app for creative thinkers. It provides an infinite canvas where you can take notes, sketch ideas, draw freely, create mind maps, and organize thoughts — all without an internet connection. Built with React, TypeScript, and Vite by Love Dhiman.

## Features

- **Offline Canvas Note-Taking** — Write notes on an infinite canvas without internet
- **Freeform Sketching & Drawing** — Sketch ideas naturally with finger or stylus
- **Mind Map Creation** — Connect related ideas visually to build mind maps
- **10 Visual Themes** — Blood Moon, Royal Gold, Electric Blue, Neon Lime, Crimson, Deep Purple, Arctic, Cream Paper, Matrix, Ferrari
- **No Account Required** — Works fully offline without any sign-in
- **No Advertisements** — Completely ad-free experience
- **Google Sign-In** — Optional cloud backup for your notes
- **Android APK** — Download and install on Android devices
- **PWA Ready** — Progressive Web App with offline support
- **Open Source** — Source code available on GitHub

- React 19
- TypeScript
- Vite
- Tailwind CSS v4
- Framer Motion
- Lenis (smooth scrolling)
- Lottie (animations)
- Firebase Auth (Google Sign-In)

## Why Grog?

Most note-taking apps require accounts, track your data, or need internet. Grog is different:

- **Private**: Everything stays on your device. No data collection.
- **Fast**: No loading screens. No sign-in required. Open and create.
- **Free**: No subscriptions, no paid plans, no in-app purchases.
- **Offline-First**: Works in airplane mode, remote areas, or anywhere without internet.
- **Creative**: Canvas-based interface lets you write, draw, and connect ideas naturally.
